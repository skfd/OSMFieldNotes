# Screenshots to capture

No device was attached when the listing was written, so the six screenshots below are still
owed. Capture on a phone at 1080x2400 or similar (Play accepts 16:9 to 9:16; keep them all the
same size), light theme, real data around a real walk if possible, no debug section visible
(use a release or a non-debug build for the Settings shot). Save as `01-notes.png` and so on
in this folder; PNGs here are not gitignored, so keep them under 1 MB each.
